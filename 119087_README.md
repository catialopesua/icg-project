## Game Overview

### Game Goal
Help Tim find his 5 friends scattered across the map so they can all celebrate his birthday party together.

### Game Controls (on computer)
- **WASD** - Move around
- **Mouse** - Look around
- **E** - Interact with friends
- **Space** - Jump

## Use of AI Tools

**Gemini** was used to generate the images of the friends and for coding efficiency.

**Github Copilot** was used in the development of the mobile integration system, code organization, animation assistency to create complex animation using mathematics, to develop the debug mode (the special mode which I used to help me place the models where I would think they look better), audio support and, finally, user interface.
